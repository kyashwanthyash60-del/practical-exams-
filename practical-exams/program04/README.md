# Program 4: UI/UX Design using Figma


## Aim
Create low-fidelity and high-fidelity screens for a Student Management System.

## Screens to design
- Login
- Admin dashboard
- Student registration form
- Student profile
- Notices list

## Steps
1. Create a Figma account and a new design file.
2. Create a desktop frame (1440 × 900).
3. Add navigation, page title, form fields and primary action buttons.
4. Create a second frame for the student profile.
5. Link Login to Dashboard in Prototype mode.
6. Share the prototype link and capture screenshots.

## Expected result
A clickable prototype with consistent spacing, typography and colors.
