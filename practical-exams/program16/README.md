# Program 16: Spring Framework Autowiring, Qualifier and Bean Scope

## Requirements
JDK 17+ and Maven. Import this folder as an Existing Maven Project in STS.

## Run
In STS: File → Import → Maven → Existing Maven Projects → select this `program16` folder → Finish. Wait for dependencies to download. Open `Test.java` → Run As → Java Application.

Expected output includes `Address [street=Second Street, city=Lucknow]` and `true` for prototype scope.
