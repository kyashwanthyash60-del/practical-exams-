# Program 5: GitHub Repository, Push, Pull and Branching


## Aim
Use GitHub to version-control a project.

## Steps
1. Create a repository named `student-management-practical`.
2. Add a README and an `index.html` file.
3. Commit the files with message `Initial commit`.
4. Create a branch named `feature/student-form`.
5. Add a student form and commit the change.
6. Push the branch and create a pull request.
7. Merge the pull request after reviewing the changes.
8. Pull the latest main branch to your local computer.

## Expected result
A GitHub repository with commits, a feature branch and a merged pull request.
