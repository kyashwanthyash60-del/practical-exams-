# Full Stack Development Practical Programs

This repository contains practical folders arranged by program number.

## Open with
- HTML, JavaScript, TypeScript and React: Visual Studio Code
- Spring Framework / Spring Boot: Spring Tool Suite (STS) or another Java IDE
- MongoDB shell: MongoDB Shell (`mongosh`)
- Docker: Docker Desktop

## Programs
- Programs 1–6: planning, Jira, Figma, Git/GitHub and cloud deployment exercises
- Programs 7–9: HTML/JavaScript/TypeScript
- Programs 10–15: React
- Program 16: Spring Framework XML configuration, autowiring and bean scope
- Program 17: Spring Boot REST CRUD with MySQL
- Program 18: MongoDB shell CRUD
- Program 19: Not specified in the supplied practical list
- Program 20: Spring Boot REST CRUD with MongoDB
- Program 21: Spring Security
- Week 11: Docker

Read the README.md inside each program before running it. Configure your own local database credentials; do not publish passwords.
