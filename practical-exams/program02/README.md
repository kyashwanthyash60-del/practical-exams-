# Program 2: Create a Product Backlog in Jira


## Aim
Create a Jira project and maintain a product backlog.

## Steps
1. Sign in to Jira and create a project using the Scrum template.
2. Name it `Student Management System`.
3. Open Backlog and create the stories listed in Program 1.
4. Assign priorities and story points (for example 3, 5 or 8).
5. Create labels such as `frontend`, `backend` and `database`.
6. Capture a screenshot of the backlog for your practical record.

## Expected result
A Jira Scrum project containing prioritized user stories.
