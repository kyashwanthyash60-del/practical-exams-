# Program 6: Basic Cloud Application Deployment


## Aim
Deploy a simple static website to a cloud hosting service.

## Steps
1. Create a GitHub repository containing an `index.html`.
2. Sign in to a static hosting provider such as GitHub Pages or another provider available to you.
3. Connect the repository.
4. Select the correct branch and publish directory.
5. Deploy and open the generated public URL.
6. Test the page in a private browser window.

## Important
Free hosting plans and provider interfaces can change. Check current pricing and never enter payment details unless you intend to subscribe.

## Expected result
A public URL that displays the deployed website.
