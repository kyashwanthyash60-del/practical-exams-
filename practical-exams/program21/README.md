# Program 21: Spring Security with HTTP Basic Authentication

Requirements: JDK 17+ and STS.

Import as Existing Maven Project and run `Program21Application.java`.

Test:
- `http://localhost:8080/public` works without credentials.
- `http://localhost:8080/secure` requires authentication.
- Username `student`, password `student123`
- Username `admin`, password `admin123`

These are demonstration-only credentials. Replace them and use HTTPS and secure password storage in real applications.
