# Program 1: Project Planning and Product Backlog


## Aim
Plan a sample Student Management System using a product backlog.

## Product vision
A web application that lets students view profiles, attendance and notices while staff manage records.

## Sample product backlog
| ID | User story | Priority |
|---|---|---|
| US01 | As an admin, I can register students | High |
| US02 | As a student, I can view my profile | High |
| US03 | As a teacher, I can record attendance | High |
| US04 | As a student, I can view notices | Medium |
| US05 | As an admin, I can generate reports | Medium |

## Acceptance criteria
- Required fields are validated.
- Only authorized staff can modify student records.
- Students can view but not edit official attendance.
- Reports show the selected date range.

## Deliverables
Save the backlog, product vision, assumptions and acceptance criteria in your project submission.
