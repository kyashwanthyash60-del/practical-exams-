# Program 3: Sprint 1 Planning


## Aim
Plan Sprint 1 using the backlog.

## Sprint goal
Allow an administrator to register students and allow students to view their profiles.

## Sprint backlog
- US01: Student registration (5 points)
- US02: Student profile view (3 points)
- Add basic form validation (2 points)
- Review and test the registration flow (2 points)

## Steps
1. Create Sprint 1 in Jira.
2. Move the selected stories from the backlog into the sprint.
3. Set a one- or two-week sprint duration.
4. Start the sprint and update task status as work progresses.
5. Review completed work and record impediments.

## Expected result
A sprint with a goal, duration and selected user stories.
